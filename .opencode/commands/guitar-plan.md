# Plan the guitar experience

Use the `web-architect` agent and the `interactive-guitar-web` skill.

Audit the current project without modifying any files. Define:

- the existing stack;
- the proposed "Screaming Architecture";
- a migration strategy, if necessary;
- domains and boundaries between `profile`, `interactive-guitar`, and `audio-experience`;
- minimum implementation stages;
- risks regarding GitHub Pages, responsiveness, and accessibility.

Deliver a concrete, file-by-file plan, and do not proceed with implementation until the plan has been documented in the response.
