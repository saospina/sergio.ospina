# Verificar la experiencia de guitarra

Usa el agente `quality-reviewer` y la skill `interactive-guitar-web`.

Revisa el diff y verifica:

- interacción de las seis cuerdas;
- cambio correcto de contenido;
- audio después de interacción;
- silencio y errores de carga;
- teclado, focus y lectores de pantalla;
- `prefers-reduced-motion`;
- responsive en móvil y desktop;
- rutas y build de GitHub Pages;
- regresiones en biografía y enlaces.

No refactorices por iniciativa propia. Devuelve hallazgos por prioridad con archivo, evidencia y corrección mínima sugerida.
