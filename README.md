# Personal Web site

### I have made my Landing Page to improve my professional profile and taking advantage of quarantine time

## Development

```sh
npm install
npm run dev
```

Build the site with `npm run build` and preview the production output with `npm run preview`.

## Deployment

The site is deployed to GitHub Pages after a pull request is merged into `master`.
Set the repository's Pages source to **GitHub Actions** under **Settings > Pages**.
